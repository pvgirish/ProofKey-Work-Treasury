ProofKey is a work-treasury prototype for contractor teams. It follows agreed outcomes from approval to payment. This Guided Demo uses test CTC, practice tokens on a test network. It is not a bank payout or real earnings.

### Scene 02 — Agreement

### Scene 03 — First outcome
